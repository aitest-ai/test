# 東新版（Dongxin edition）：把東新國小建模套上 slice 系統

入口：`dongxin.html`（`src/main_dx.js`）。與 `index.html`（示意切片）共用 **相機、輸入、UI、角色、材質、Batch、導航 walker、測試工具**；差別只在「資料 → 世界」這一層。

## 資料證據分級（本版）

| 等級 | 內容 | 來源／說明 |
|---|---|---|
| **A 直接取自圖面資料** | 場地外框（`site`）、各層房間矩形（`rooms`）、梯間矩形（`stairs`）、各層走廊遮罩（`masks`）、樹位（`trees`）、地點座標（`places`）、底圖影像 | 由使用者先前上傳的設計圖（平面圖／DWG）轉出，存於 `data/dongxin_geo.json`、`assets/dongxin_plan*.jpg`。**格網化**（每格約 0.30 m），房間貼齊格線。 |
| **B 有根據的推論** | 比例尺 0.0756 m/px、層高 3.9 m、B1＋1F–4F 的層級對應、雙跑 U 形梯幾何、門的位置（程式依走廊相鄰自動挑選）、走廊連通修復（孤島接回主走廊）、梯間與房間邊界貼合 | `model.js`（原 `nav.js`）。這些是**為了可走而做的建模決定**，不是圖面直接寫的。 |
| **C 示意／未證實** | 房間**名稱**（暫定）、各處精確尺寸、外牆與室內材質、教室內裝（目前只有黑板）、B1 內部（只有外框與車道面）、校門／圍牆細節、樹種與樹冠大小、招牌文字 | 立面語彙（灰框玻璃隔間＋木門、綠色欄杆、圓柱）沿用 slice 對東新新校舍照片的觀察。 |

**未經校方測繪，不可當作精確還原。** UI 頂部徽章、資訊卡與說明視窗都會標示「圖面推得・名稱暫定・非校方測繪」。

## 架構（這次新增／改動）

```
data/dongxin_geo.json        ← 資料層（A 級）；assets/dongxin_plan*.jpg ← 地面底圖（原圖 / 柔化版）
src/dongxin/model.js         ← 資料 → 格網世界：房間、走廊遮罩、梯間、門、可走格(NAV/ERO)、A* 路徑規劃（原 app/nav.js，改為 buildModel(D)，無 three.js 依賴）
src/dongxin/world.js         ← 物理層，介面與 slice 的 collision.js 相同：hit / surfaceY / move / ray / los / ceilingY
src/dongxin/nav.js           ← 導航層：格網 A* 走廊／戶外 + 明確樓梯 waypoint → 與 slice 相同的 route 格式
src/dongxin/scene.js         ← 場景工廠：用 Batch + slice 材質生成牆、走廊玻璃隔間、門、欄杆、圓柱、雨遮、地面、圍牆、樹
src/main_dx.js               ← 主程式：slice 相機／輸入／UI，加上樓層選單(含 B1)、小地圖、地點清單
src/nav/navgraph.js          ← 共用 walker（新增 tol 參數）
```

### 與舊版（單檔 app.js）的關鍵差異
1. **樓梯不再是腳本動畫**：梯級、平台是可站立表面，人物用同一個 `move()` 走上去；手動（W）與自動導航行為一致。梯口中央是分隔牆，所以加了「梯口導引」：朝梯間直走時輕推向最近的梯跑中線。
2. **鏡頭**：沿用 slice 的指數平滑＋遮擋收近，並新增三項限制——(a) 收近改為沿視線等比（視線方向不變）、(b) 繞角色方位角速度上限（2.6 rad/s；被遮擋時 3.4）、(c) 鏡頭速度上限（約 13 m/s）。同一組限制也回補到 slice（`main.js`）。
3. **碰撞**：圓（R=0.3）的 5 個取樣點必須落在「該層可走格」或「梯面」上；與視覺幾何分離。

## 已知限制（誠實清單）
- 房間名稱為暫定；教室內只有黑板，沒有桌椅（桌椅需要碰撞才不穿，尚未做）。
- 柱子只擋鏡頭、不擋身體（柱位在走廊邊緣，身體最多與柱重疊 0.17 m）。
- B1 內部幾乎是空的（外框與車道面）。
- 沒有 4F 以上的屋頂設備、沒有梯塔頂與時鐘以外的細節；校門只有藍色伸縮門與校名牆。
- 手機只測了版面截圖，**未在實體手機上測觸控**。
- 路徑到終點是**房間中心**（最近可走格），不是門口；戶外地點是最近可走格。
