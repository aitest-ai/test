# 校園漫遊實驗室 / Campus Atlas prototype 01

依據已分析的 3DTYPSMap 技術方向，**重新獨立撰寫**的 Three.js 3D 校園原型，不包含原網站的專有模型、貼圖或原始碼。

## 第一版功能

- 原創程式化建築（教室門、磁磚、走廊、欄杆、屋頂、樓層、標示、室內桌椅）
- 戶外球場、植栽、步道、圍牆、校園入口與照明
- 鳥瞰旋轉 / 縮放，點選建築與教室
- 鳥瞰分層檢視（隱藏所選樓層以上的場景）
- 第三人稱角色與 WASD 行走、基本建築阻擋、Shift 加速
- 校園搜尋、路線 BFS 網格尋路、行走引導、右下角即時小地圖
- 手機版基本觸控拖曳及虛擬搖桿

## 原型界線

這一版的東新國小名稱只表示**將來要以此為目標重建**。建築、場地、位置、樓層及教室均為**虛構示意**，不是實測的東新國小配置。實作採用獨立原創程式化素材，沒有拿原作者網站的專有模型或教室資料。

## 快速執行

任何靜態網站伺服器皆可，例：`python -m http.server 8000`，瀏覽 `http://localhost:8000`。

本版使用 Three.js r128 的 CDN 版本（`cdnjs.cloudflare.com`）。用網頁伺服器開啟，避免直接用 file:// 執行 JS module。

## 下一階段怎麼換成真的東新國小

請修改 `src/schoolData.js` 的 `school.buildings`：每棟的 `x,z,width,depth,floors,floorHeight,rooms`。現階段建築為直線型量體，下一版需依實測圖加入 L 型、多棟連接、真實樓梯、室內碰撞、照片 PBR 材質與校內精確路網。

## 專案原則

- 未經測量的配置不視為真實資訊。
- 不以生成的示意圖代替精確建築測繪。
- 避免擷取及重發第三方專有 3D 素材。
