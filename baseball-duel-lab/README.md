# 第九局 · BASEBALL DUEL LAB v0.2（物理校正預覽）

原創 Three.js 網頁棒球投打練習原型。借鑑 2.5D 羽球遊戲「減少操作負擔、重視動作與球路」的設計理念，不使用 Badminton Duel 的模型、圖像、程式原始碼或通訊協定。

## 現有功能
- 3D 棒球場、球員、投手動作、投球與擊球軌跡、第三人稱打擊視角
- 四球種：四縫線直球、曲球、滑球、變速球（速度、橫移、下墜各有差異）
- 三種難度、瞄準打擊點、揮棒時機視窗、球棒動畫、擊球飛行、初速 / 仰角 / 距離回饋
- 好球、壞球、三振、四壞保送、界外球、安打、全壘打及出局的**簡化訓練判定**
- 基本壘包狀態以及單人練習分數；手機觸控瞄準與揮棒按鈕

## 控制
- 拖曳打擊區九宮格 / WASD / 方向鍵瞄準
- `空白鍵` 揮棒，或按右側按鈕；球未開始時按 `Enter` 投球
- 進入場景後可點右上問號看操作說明

## 起動
- 以任何靜態檔案伺服器啟動，如 `python -m http.server 8000`，瀏覽 http://localhost:8000/
- Three.js ESM 模組使用固定版本 `three@0.180.0` 的 jsDelivr CDN，需要網路。
- Vercel：靜態部署，專案 Root Directory 使用 `baseball-duel-lab`。

## 物理與功能邊界
本版的球路使用定時積分、重力、速度平方阻力與**簡化的旋轉偏轉加速度**；未標定真實棒球的升力係數、轉速、縫線效應，也未實作實際棒球規則引擎。打擊已改為與畫面相同的 90 公分球棒掃掠線段碰撞，使用相對棒速與球速估計碰撞反彈，但仍非完整球棒彈性模型；落點以模擬飛行近似，沒有精密球棒碰撞網格、即時守備 AI、完整跑壘、真正連線及伺服器仲裁。稱為可玩原型，不宣稱物理真實或多人連線完成。

## 後續架構
1. 分離 physics/world/network，建立固定 60Hz 計算及可重播事件種子。
2. 加入撞擊點棒球物理、好球帶個人化及公平/界外精確判定。
3. 建立 Colyseus 或權威 WebSocket 伺服器與遊戲房間，加入預測、回溯與延遲補償。
4. 加入完整棒球規則與守備、跑壘、多人觀戰聊天。

## v0.2 修正紀錄（2026-10-15）

- 修正上一版球棒長度 2m、模型方向與實際判定脫鉤的重大問題；本版以單一 `batPose()` 驅動 Three.js 棒身幾何和碰撞判定。
- 球棒 0.90m，棒球半徑 0.0366m（為畫面可視性另行略微放大渲染模型）。
- 改為 120Hz 固定時間步進、16 個子樣本進行掃掠球棒與球的接觸測試，避免球高速穿透棒身。
- 以質量、反彈係數、撞擊法向及棒速估算擊球速度，取消虛構的精準命中初速與仰角直接給值。
- 投球加入平方速度阻力及按球種不同方向的近似旋轉力，以數值修正初始速度讓球抵達落點。
- 本分支對應 GitHub Actions QA： https://github.com/aitest-ai/test/actions/runs/38748767278 。
- 尚未驗證真實人體握棒姿勢及投手/打者骨架動作；棒球轉速、空氣力學係數仍屬簡化，沒有實測標定。沒有多人連線。
