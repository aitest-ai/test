## 回答：能否完整複製？

**REA 不支援一鍵複製整個網站及私有後端。**
可行的是使用 REA 分析公開客戶端及可重現操作流程，再**獨立實作**同等功能的網球版：
Three.js 2.5D 球場、原創角色/球拍、網球球路與拍面碰撞、單雙打 AI、網球計分規則、線上房間/觀戰/聊天、桌機及手機控制。

不能直接照搬原羽球模型、程式、素材與羽球物理：網球需要落地反彈、上旋/切削、球網與場界以及網球發球及計分。

## 必須補的 REA 觀察

1. 實際 AI 單打：完整一球、各種擊球、比分、回放。
2. 實際雙打：站位、輪換、搭檔行為。
3. 兩個自有測試客戶端：房間建立、WebSocket/RTC 同步、斷線復原；不觀察或干擾他人非公開會話。
4. 重跑包含 script source 的 REA inspect，檢查 source maps，僅用來抽取結構證據，不重新散布原站原始碼。
5. 用 REA 的場景比較/義務清單，逐項查核替代網球版的行為一致性。

## 嚴格驗收

必須先通過「球拍 3D 方向與碰撞法向一致」＋「網球落地、旋轉、飛行」＋「完整單人比賽」才進入多人連線。沒有兩端實際測試不能稱完成網路對戰。
